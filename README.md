## Projects

**[Cross-Border Multi-Currency Ring Fraud & Dynamic AML Network](#)**  
Money laundering rarely looks suspicious one transaction at a time — it shows up as a *shape* in
the network. This models cross-border, multi-currency transactions as a graph and finds those
shapes: community detection for clusters, centrality for the accounts holding a ring together,
and cycle detection for money that returns to where it started. Outputs a risk score per entity
plus the structural evidence behind it, so an analyst can see *why* something was flagged.

`Python` · `Graph Analytics` · `Community Detection` · `Centrality` · `Cycle Detection`

**[AutoDS Agent — Automated Data Science Pipeline](#)**  
Point it at a raw CSV and it does the first day of work for you: cleans the data, runs EDA,
engineers features, and recommends models — with an LLM explaining the reasoning behind each
recommendation rather than just returning a leaderboard. Built as cooperating agents so each
stage can be inspected and corrected independently.

`LangChain` · `Ollama` · `Python` · `Scikit-learn` · `Agentic AI`

**[Hospital Readmission Analysis](#)**  
Which patients come back, and what about their admission predicted it? SQL for the data
preparation and cohort definition, Python for the analysis and modelling.

`SQL` · `Python` · `Pandas` · `Healthcare Analytics`

**[PSX Market Analytics Data Warehouse](#)**  
Star-schema warehouse for Pakistan Stock Exchange data, with analytical SQL views sitting on top
for reporting — built to practise dimensional modelling on real market data rather than a
textbook dataset.

`SQL` · `Star Schema` · `Data Modelling` · `ETL`
