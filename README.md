## About

I work across the data science pipeline — SQL data modelling, exploratory analysis, machine
learning, and LLM-based agents. Most of my recent work sits in two areas: graph analytics for
fraud and anti-money-laundering detection, and agentic AI systems that automate parts of the
data science workflow.

**Currently building:** AutoDS Agent — an agentic system for automated data preparation, EDA,
feature engineering and model recommendation, built with LangChain and local LLMs via Ollama.

## Featured Projects

### Cross-Border Multi-Currency Ring Fraud &amp; Dynamic AML Network
Detects money-laundering rings in cross-border, multi-currency transaction networks. Models
transactions as a graph and applies community detection, centrality analysis and cycle detection
to surface ring structures, then produces risk scores with explainable output for analyst review.

`Python` · `Graph Analytics` · `Community Detection` · `Centrality` · `Cycle Detection`

### AutoDS Agent — Automated Data Science Pipeline
An agentic system that takes a raw dataset and runs it end to end: automated cleaning,
exploratory analysis, feature engineering, and model recommendation, with LLM-generated
explanations of why each model was suggested.

`LangChain` · `Ollama` · `Python` · `Scikit-learn` · `Agentic AI`

### Hospital Readmission Analysis
Healthcare analytics project examining which patient and admission factors are associated with
hospital readmission, using SQL for data preparation and Python for analysis and modelling.

`SQL` · `Python` · `Pandas` · `Healthcare Analytics`

### PSX Market Analytics Data Warehouse
A star-schema data warehouse for Pakistan Stock Exchange market data, with analytical SQL views
built to support downstream reporting and BI.

`SQL` · `Data Modelling` · `Star Schema` · `ETL`
