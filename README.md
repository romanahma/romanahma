## About

Data Scientist working across the full pipeline — from SQL data modelling and exploratory analysis
through to machine learning systems and LLM-based agents. Strongest areas are Python, SQL,
supervised ML, and graph analytics. Recent work focuses on agentic AI systems that automate parts
of the data science workflow, and on graph-based fraud and anti-money-laundering detection.

**Currently building:** AutoDS Agent — an agentic system that automates data cleaning, EDA, feature
engineering and model recommendation using LangChain and locally-hosted LLMs via Ollama.

## Featured Projects

### Cross-Border Multi-Currency Ring Fraud & Dynamic AML Network
Graph-based anti-money-laundering system for detecting fraud rings across multi-currency,
cross-border transaction networks. Applies community detection, centrality analysis and cycle
detection to surface suspicious structures, with risk scoring and explainable output for analyst review.

`Python` `Graph Neural Networks` `PyTorch Geometric` `NetworkX` `Graph Analytics`

### AutoDS Agent — Automated Data Science Pipeline
Multi-agent system that takes a raw dataset and runs it end-to-end: automated cleaning, exploratory
analysis with interactive visualisations, model selection across a library of algorithms, and
LLM-generated explanations of why each model was recommended.

`LangChain` `Ollama` `Python` `Scikit-learn` `Streamlit` `Plotly`

### Hospital Readmission Risk Prediction
End-to-end ML system predicting patient readmission risk, served through an API with an interactive
dashboard and SHAP-based interpretability so clinical users can see what drives each prediction.

`LightGBM` `Flask` `Streamlit` `SHAP` `Pandas`
→ [github.com/romanahma/Readmission-Hospital](https://github.com/romanahma/Readmission-Hospital)

### PSX Market Analytics Warehouse
Layered star-schema data warehouse for Pakistan Stock Exchange market data, with analytical SQL
views built for downstream BI and reporting.

`PostgreSQL` `SQL` `Data Modelling` `ETL`
